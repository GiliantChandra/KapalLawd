# Buku Log Keabadian: Tragedi Rekayasa AI & Epik Penyelesaian Masalah

Berikut ini adalah dewan arsip kronologis catatan permasalahan luar biasa tingkat ancaman mati (_bottleneck paralyzer_) yang bertubi-tubi bermunculan memperingatkan keruntuhan proyek ini selama masa inkubasi pengembangan, bersama literatur tentang bagaimana sang solusi teknis tingkat dewa diselenggarakan guna mengamankan peluncuran produk akhir.

## 1. Tragedi Penolakan VRAM ("CUDA Out of Memory & Koma Fatal Hardware")
* **Deskripsi:** Saat Stable Diffusion Inpainting ditugaskan memuntahkan karya perdananya, Komputasi Pipa Model Tensor membengkak, mencekik limitasi memori fisik grafis PC (VRAM) milik The NVIDIA RTX 3050. Terminal terhenti bekerja menolak menjalankan program (Freeze Engine CUDA).
* **Solusi Mutlak:** Serangkaian suntikan penekan sistem disepakati. Seluruh parameter kode diubah mutlak menggunakan *Full Precision 16 Bits Tensor* melalui fungsi ajaib tak terlihat parametris `torch_dtype=torch.float16` memotong ukuran struktur model setengah kali lebih ringan tanpa mencekik kejernihan, ditingkatkan lagi bersama skrip pemotong bongkahan kargo perhitungan otak menjadi lajur-lajur kecil beriringan dari HuggingFace (yang disebut fitur ramah memori `enable_attention_slicing()`). AI menghembuskan napas lancar dan tak pernah terinfeksi batuk RAM lagi.

## 2. Penghalang Tembok Besar Uang (Kasus "Firebase Storage Blaze Plan Paywall")
* **Deskripsi:** Aplikasi Flutter berhenti merespon dan gagal mengantarkan laporan foto final ke riwayat pengguna (Layar History nge-blank) saat Firebase Storage menghunuskan batas tagihan berbayar dan memblokir unggahan massal ke lingkungan Google *Storage Bucket* karena tidak mengikat kartu identitas kredit rekening bank sebagai Developer Penguji.
* **Solusi Mutlak:** Ide radikal merubah paradigma aplikasi diinisiasi. Firebase Storage ditinggalkan. Aplikasi Python Laptop direparasi tidak lagi hanya bertugas sebagai AI Gen, namun merangkap tugas berat menjadi *Statical File Content Hosting Server* layaknya server Apache milik Wikipedia. Folder rahasia riwayat diciptakan `backend/history/`. Aplikasi Flutter merotasi panahnya menjauh dari awan Firebase menuju celah pelabuhan jaringan komputer lokal untuk menyerap rekam foto tersebut secara murni tanpa hambatan uang sepeserpun selama PC bersirkulasi terhubung jaringan LAN/Intranet Wi-fi yang disatukan. Sebuah jalan lolos yang mutakhir.

## 3. Wabah Mutasi Anatomi Mahakarya ("Sindrom Bagian Belakang Kepala / Muka Tumor")
* **Deskripsi:** Pada saat model uji pemotretan rambut ekor "Mullet", AI merespon sinyal ketakutan dengan menjahit kulit punggung atau mencetak "Wajah Tambahan" asing bertaring di area pelipis pipi, melepaskan rambut di udara secara horor dan sangat ganjil (absurd).
* **Solusi Mutlak:** Sinyal kesalahan ditemukan pada ketidaktahuan komputer memahami batas kanvas (Ilmu Geometri Wajah). Kode pelindung (Masking OpenCV) era lama hanya memegang perisai persegi kaku di kening pengguna, membiarkan daerah lekukan telinga/kerah terbuka untuk dilukis buas oleh Stable Diffusion. Masker pelindung dibakar. Sebuah pelindung telur ajaib radius 3D *(Ellipse Math Radius)* dipertimbangkan untuk mengelilingi pas persis garis lengkung dagu dan pinggiran lebar tulang pelipis. Titik luar radius diberi pelumas lumer efek Gauss (Gaussian Blur 31x31 dimensi) membius pinggiran pelindung menjadi embun penyamar. Wajah user terlindungi seperti dewa dan AI hanya berfokus meledakkan warna mahakaryanya pada kanvas bahu dan sisa rambut saja.

## 4. Bencana Visual Wajah Tertindih Lempengan (Tragedi Muka / Wajah Gepeng)
* **Deskripsi:** Mahakarya foto telah sempurna namun satu distorsi mencolok dilaporkan; Kepala Pengguna seolah terhimpit gravitasi hingga menggepeng *(Stretched and Flattened)* secara mendatar memaksakan kemiripannya terbuang lenyap.
* **Solusi Mutlak:** Analisis menyingkap skrip manipulasi kanvas lama OpenCV memanggil titah `Image.resize((512, 512))` yang sewenang-wenang menghimpit frame murni rasio 3:4 persegi panjang Smartphone berdiri (Portrait Selfie) ke dalam kaleng bujur sangkar 1:1 alat *Machine Learning Diffusion*. Untuk menghindari pemotongan paksa rahang tengah yang mengerikan, arsitektur `ImageOps.pad` diwujudkan. Alih-alih merusak tulang visual, sistem mengkerutkan wajah secara rasional proporsi seraya menambah Sabuk Pilar Hitam di sisi layar kosong (Sebuah efek Bioskop *Letterboxing*). Sebagai keajaiban estetika alam semesta, AI melihat kekosongan pinggiran piksel hitam tersebut, takjub, lalu secara radikal memanfaatkan kekosongan tersebut melukis "Dinding Set Abu-Gelap Skena Studio Foto Komersil 8k". Kegagalan menyulap diri menjadi maha keuntungan artistik.

## 5. Mitos Kebutaan Sang Mata Bionik ("Bug Miring Fatal 90 Derajat Sensor Tidur")
* **Deskripsi:** Operasi terakhir sistem tak dapat mengeja foto wajah sama sekali. Jantung mesin detektor wajah di OpenCV menembakkan balasan sinis log error terminal `[FATAL] 0 MUKA TERDETEKSI!`. Pemotong otomatis gagal jalan, rambut tidak berubah di layar apapun sekeras apapun skrip melaju komputasinya.
* **Solusi Mutlak:** Inspeksi *cyber* meta-forensik mendokumentasikan fakta yang menggelitik perut—Kamera Smartphone Android meludah keluar sensor kamera dengan posisi bingkai melebar *(Landscape / Tidur/ Rebahan)* dan diam-diam menyerahkan instruksi *Orientaion String EXIF Tag* (sebuah stiker instruksi perbaikan) pada OS penampil media untuk "Tolong Rotasikan Foto ini Menjadi Berdiri saat Anda Menampilkannya". OpenCV yang buta pada stiker metadata menelan mentah-mentah file tersebut dan panik mendeteksi seorang leher yang sedang tidur terbalik horizontal dari sisi ke sisi. Kode pembuluh algoritma Python diiris ulang dan disuntik barisan *anti-venom* `ImageOps.exif_transpose`! Kini sistem dipaksa menginterogasi bacaan rotasi OS Smartphone lalu meng-ungkit manual foto hingga di posisi tegak berdiri memanjang ke angkasa, barulah sistem pemindai OpenCV diaktifkan serigala. Masalah membusuk pun tersapu bersih sampai tuntas, menorehkan jalan sejarah rilis terakhir aplikasi ini yang bersih dari racun fatal.
